## 1. Finalidad del documento

Este documento organiza el trabajo de las cuatro primeras unidades de programación del módulo.

Tiene dos finalidades:

1. Servir como planificación docente para preparar e impartir las clases.
    
2. Servir como itinerario de estudio personal para consolidar los conocimientos técnicos y didácticos necesarios para impartir DIW.
    

La planificación se ajustará a los contenidos, resultados de aprendizaje y criterios de evaluación establecidos en la programación oficial.

**Importante:** preparar un contenido no significa haberlo impartido. El seguimiento distinguirá siempre entre preparación, impartición y evaluación.

## 2. Resultados de aprendizaje del módulo

La programación contempla seis resultados de aprendizaje:

|Código|Resultado de aprendizaje|
|---|---|
|RA1|Planifica la creación de una interfaz web valorando y aplicando especificaciones de diseño.|
|RA2|Crea interfaces web homogéneos definiendo y aplicando estilos.|
|RA3|Prepara archivos multimedia para la web, analizando sus características y manejando herramientas específicas.|
|RA4|Integra contenido multimedia en documentos web valorando su aportación y seleccionando adecuadamente los elementos interactivos.|
|RA5|Desarrolla interfaces web accesibles, analizando las pautas establecidas y aplicando técnicas de verificación.|
|RA6|Desarrolla interfaces web amigables analizando y aplicando las pautas de usabilidad establecidas.|

En las UD1-UD4 se trabajarán principalmente los fundamentos de planificación visual y creación de interfaces mediante HTML y CSS. Los resultados de aprendizaje relacionados con multimedia, accesibilidad y usabilidad tendrán su desarrollo específico en las unidades posteriores, sin perjuicio de las conexiones que se puedan establecer.

## 4. Organización de las unidades

### UD1. Planificación de interfaces y prototipado UX/UI

**Duración:** 9 sesiones.

**Finalidad:** comprender cómo se planifica una interfaz web antes de comenzar su desarrollo.

Contenidos oficiales:

- Principios del diseño visual.
    
- Percepción visual.
    
- Jerarquía tipográfica.
    
- Teoría del color.
    
- Psicología de la forma.
    
- Composición de pantallas web.
    
- Identificación de marca.
    
- Guías de estilo.
    
- Paletas de colores corporativos: HEX, RGB y CMYK.
    
- Tipografías y componentes visuales.
    
- Interpretación y aplicación de manuales de estilo.
    
- Técnicas de bocetado.
    
- Mapas de navegación.
    
- Wireframes.
    
- Prototipos interactivos navegables o mockups.
    
- Herramientas de diseño y prototipado.
    

**Vinculación principal:** RA1.

**Evidencia de aprendizaje prevista:** diseño de una propuesta de interfaz que incluya criterios visuales, guía de estilo, estructura de navegación y prototipo.

### UD2. Estructura HTML y semántica HTML5

**Duración:** 10 sesiones.

**Finalidad:** construir la estructura y el contenido de una página web utilizando HTML5 de forma correcta y semántica.

Contenidos oficiales:

- Sintaxis HTML.
    
- Estructura básica de un documento.
    
- Etiquetas `html`, `head`, `title` y `body`.
    
- Comentarios.
    
- Anidamiento.
    
- Atributos globales.
    
- Estructura semántica HTML5.
    
- Elementos `header`, `nav`, `main`, `article`, `section`, `aside` y `footer`.
    
- Categorías de contenido.
    
- Formularios HTML5.
    
- Elementos `input`, `select` y `textarea`.
    
- Tipos de entrada `email`, `date`, `color`, `range` y `number`.
    
- Atributos de validación.
    
- Elemento `progress`.
    

**Vinculación principal:** estructura de documentos web y preparación de la base necesaria para aplicar estilos en la UD3.

**Evidencia de aprendizaje prevista:** desarrollo de páginas HTML5 correctamente estructuradas, semánticas y con formularios funcionales a nivel de marcado y validación nativa.

### UD3. Estilos CSS y modelo de cajas

**Duración:** 12 sesiones.

**Finalidad:** controlar la presentación visual de los documentos HTML mediante hojas de estilo CSS.

Contenidos oficiales:

- Sintaxis CSS.
    
- Reglas y selectores.
    
- Asociación de CSS:
    
    - Estilos externos.
        
    - Estilos internos o incrustados.
        
    - Estilos en línea.
        
- Tipografía y texto.
    
- Colores y sistemas de representación.
    
- Propiedades de fuente y alineación.
    
- Modelo de cajas:
    
    - `content`.
        
    - `padding`.
        
    - `border`.
        
    - `margin`.
        
    - `box-sizing`.
        
- Propiedades `display`.
    
- Valores `inline`, `block`, `inline-block`, `flex` y `none`.
    
- `overflow`.
    
- `z-index`.
    
- Posicionamiento:
    
    - `static`.
        
    - `relative`.
        
    - `absolute`.
        
    - `fixed`.
        
    - `sticky`.
        

**Vinculación principal:** RA2.

**Evidencia de aprendizaje prevista:** transformación de documentos HTML en interfaces visualmente coherentes mediante CSS, aplicando correctamente el modelo de cajas y las propiedades de disposición y posicionamiento.

### UD4. CSS3 avanzado, Grid/Flex y Responsive Web Design

**Duración:** 16 sesiones.

**Finalidad:** desarrollar interfaces adaptables a distintos dispositivos y resoluciones mediante técnicas avanzadas de CSS.

Contenidos oficiales:

- Selectores avanzados.
    
- Combinadores.
    
- Pseudoclases.
    
- Pseudoelementos.
    
- Estados `hover` y `focus`.
    
- Selectores de validación y posicionales.
    
- Diseño responsive.
    
- Viewport.
    
- Filosofía Mobile First.
    
- Media Queries.
    
- Breakpoints.
    
- Flexbox avanzado:
    
    - `flex-basis`.
        
    - `flex-grow`.
        
    - `flex-wrap`.
        
    - `gap`.
        
- CSS Grid:
    
    - Filas y columnas.
        
    - Unidad `fr`.
        
    - `auto-fill`.
        
    - `auto-fit`.
        
    - Áreas y líneas.
        
- Transformaciones 2D y 3D.
    
- Transiciones.
    
- Animaciones con `@keyframes`.
    

**Vinculación principal:** profundización en la creación de interfaces homogéneas y adaptables.

**Evidencia de aprendizaje prevista:** desarrollo de una interfaz responsive que combine selectores avanzados, Flexbox, Grid y efectos CSS.

## 6. Metodología de trabajo

La programación oficial establece una metodología fundamentalmente práctica, basada en la experimentación y la resolución de problemas.

Aplicaremos esta secuencia habitual:

1. Presentación del problema o necesidad.
    
2. Explicación teórica del concepto.
    
3. Demostración guiada.
    
4. Ejercicio acompañado.
    
5. Ejercicio individual.
    
6. Revisión y corrección.
    
7. Reflexión sobre errores y alternativas.
    

Se priorizará que el alumnado comprenda por qué se utiliza cada técnica, no solamente que memorice propiedades o etiquetas.

## 7. Sistema de evaluación y evidencias

Se utilizarán los instrumentos contemplados en la programación:

- Observación directa del trabajo diario.
    
- Actividades y prácticas individuales o grupales.
    
- Pruebas teóricas.
    
- Pruebas prácticas.
    
- Rúbricas.
    
- Listas de verificación.
    
- Trabajos y exposiciones.
    

La programación establece esta distribución para la calificación de los criterios:

|Instrumento|Porcentaje|
|---|---|
|Examen teórico|30 %|
|Examen práctico|60 %|
|Actividades en aula|10 %|

Las actividades de cada unidad se relacionarán con sus criterios de evaluación concretos. No se asignarán criterios específicos a ejercicios hasta revisar su correspondencia con la programación.

La planificación se revisará cuando:

- Se confirme qué contenidos se impartieron antes de la incorporación docente.
    
- Se conozca el avance real del grupo.
    
- Se detecten dificultades de aprendizaje.
    
- Sea necesario reorganizar las sesiones sin alterar los objetivos y contenidos oficiales.
    

**Criterio fundamental:** la programación oficial determina qué debe enseñarse; el seguimiento real determina qué se ha enseñado; y las necesidades del alumnado determinan qué debe reforzarse.
