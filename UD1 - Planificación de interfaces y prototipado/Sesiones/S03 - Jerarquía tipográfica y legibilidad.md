# S03. Jerarquía tipográfica y legibilidad

## 1. Introducción

La tipografía no sirve únicamente para mostrar palabras. También ayuda a organizar la información y a indicar qué debe leerse primero. Una interfaz puede contener información excelente y, sin embargo, resultar difícil de utilizar si sus textos son pequeños, están mal espaciados o no existe diferencia entre títulos y párrafos.

En esta sesión estudiaremos cómo elegir y organizar tipografías desde el punto de vista del diseño de interfaces. El objetivo no es decorar el texto, sino facilitar su lectura y comprensión.

## 2. Objetivos

- Diferenciar familia tipográfica, tamaño, peso y estilo.
- Comprender la relación entre tipografía y legibilidad.
- Crear una jerarquía de títulos, subtítulos y texto.
- Identificar problemas habituales de lectura.
- Justificar una selección tipográfica adecuada para pantalla.

## 3. Conceptos previos

Debes conocer la jerarquía visual y los principios de consistencia, contraste y alineación.

## 4. Anatomía básica de la tipografía

Una familia tipográfica es un conjunto de caracteres diseñados con rasgos visuales comunes. En una interfaz podemos utilizar una o varias familias, pero cada elección debe tener una razón.

### 4.1. Clasificaciones generales

- **Serif:** las letras presentan remates o terminaciones. Algunas familias se utilizan en textos editoriales y títulos.
- **Sans serif:** no presentan esos remates. Son habituales en interfaces digitales por su variedad y apariencia.
- **Monoespaciadas:** cada carácter ocupa el mismo ancho. Son frecuentes en código y datos técnicos.
- **Display o decorativas:** tienen personalidad visual marcada y suelen reservarse para usos concretos.

No existe una familia universalmente mejor. La elección depende del contexto, el contenido, el tamaño y la identidad visual.

### 4.2. Propiedades tipográficas

| Propiedad | Qué controla |
|---|---|
| Familia | Diseño de los caracteres |
| Tamaño | Dimensión del texto |
| Peso | Grosor visual |
| Estilo | Por ejemplo, normal o cursiva |
| Interlineado | Distancia vertical entre líneas |
| Alineación | Posición del texto dentro de su espacio |
| Longitud de línea | Cantidad de caracteres por línea |

## 5. Legibilidad y lectura en pantalla

La legibilidad describe la facilidad con la que se distinguen los caracteres y se lee un texto. Depende de varios factores:

- Tamaño suficiente para el contexto.
- Contraste adecuado con el fondo.
- Espaciado entre líneas.
- Longitud de línea razonable.
- Familia tipográfica apropiada.
- Organización clara en párrafos y títulos.

No existe un único tamaño que funcione para todos los dispositivos y situaciones. Hay que comprobar el resultado en el contexto real de uso.

### 5.1. Interlineado

Un interlineado demasiado reducido hace que las líneas parezcan amontonadas. Uno excesivo puede dificultar la relación entre ellas.

### 5.2. Longitud de línea

Las líneas excesivamente largas obligan a recorrer grandes distancias con la mirada. Las demasiado cortas generan muchos saltos. El ancho del bloque de texto debe facilitar una lectura continua.

### 5.3. Alineación

- A la izquierda: suele facilitar el seguimiento de líneas en textos de lectura occidental.
- Centrada: puede funcionar en títulos breves, pero no suele ser adecuada para párrafos largos.
- Justificada: crea bordes rectos a ambos lados, pero puede generar espacios irregulares entre palabras.

## 6. Construir una jerarquía tipográfica

Una jerarquía tipográfica define niveles reconocibles.

Ejemplo:

1. Título principal: identifica el tema de la página.
2. Título de sección: introduce un bloque.
3. Subtítulo: divide una sección.
4. Texto normal: desarrolla la información.
5. Texto auxiliar: muestra aclaraciones o metadatos.

La jerarquía no depende solo del tamaño. También puede utilizar peso, espaciado, posición y estilo. Es importante mantener el mismo criterio en páginas equivalentes.

## 7. Ejemplo comentado

Una página de un curso puede organizarse así:

- «Desarrollo web» como título principal.
- «Módulos del curso» como título de sección.
- «Primer trimestre» como subtítulo.
- Un párrafo breve que explica el contenido.
- Una nota auxiliar con la duración.

Si todos los textos tienen el mismo tamaño y peso, el usuario debe leerlos para descubrir su función. Si existe una jerarquía consistente, puede reconocer la estructura de un vistazo.

## 9. Reto: sistema tipográfico

Define un sistema tipográfico para una web educativa. Debe contemplar título principal, títulos de sección, subtítulos, párrafo, texto auxiliar y enlaces.

Explica por qué has elegido una familia principal y cómo mantendrías la coherencia entre páginas.

## 10. Errores frecuentes

- Utilizar demasiadas familias tipográficas.
- Elegir una fuente solo por su apariencia.
- Crear una jerarquía basada únicamente en tamaños.
- Usar párrafos largos centrados.
- Reducir demasiado el texto auxiliar.
- No comprobar el resultado en pantalla.

## 11. Buenas prácticas

- Limita el número de familias.
- Define niveles y reutilízalos.
- Prioriza la lectura antes que el efecto decorativo.
- Mantén una longitud de línea cómoda.
- Diferencia títulos y texto mediante varios recursos coherentes.
- Comprueba la presentación en distintos tamaños de pantalla.

## 12. Resumen

La tipografía transmite contenido y estructura. Familia, tamaño, peso, interlineado y alineación influyen en la legibilidad. Una jerarquía clara permite reconocer títulos, secciones y texto normal sin tener que analizar cada palabra.
