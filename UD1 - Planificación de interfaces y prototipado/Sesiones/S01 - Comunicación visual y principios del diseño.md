# S01. Comunicación visual y principios del diseño

## 1. Introducción

Una interfaz web no es únicamente un conjunto de elementos colocados en una pantalla. Es un medio de comunicación: presenta información, permite realizar tareas y orienta a las personas para que sepan qué pueden hacer y cómo hacerlo.

Cuando alguien entra en una página, normalmente no lee cada palabra desde el principio. Primero obtiene una impresión general: identifica zonas, reconoce elementos familiares y busca señales que le indiquen dónde está la información que necesita. Por eso, el diseño visual debe ayudar a comprender la interfaz, no limitarse a decorarla.

En esta unidad aprenderemos a planificar una interfaz antes de construirla. En esta primera sesión nos centraremos en la comunicación visual y en los principios básicos que permiten organizar una pantalla.

## 2. Objetivos de aprendizaje

Al terminar este tema deberías poder:

- Explicar qué es la comunicación visual aplicada a una interfaz web.
- Diferenciar contenido, estructura visual y decoración.
- Identificar los objetivos que debe cumplir una interfaz.
- Reconocer principios básicos de diseño: claridad, jerarquía, consistencia, proximidad, alineación, contraste y equilibrio.
- Analizar una pantalla y justificar qué aspectos facilitan o dificultan su comprensión.

## 3. Conceptos previos

Conviene conocer estos términos:

- **Interfaz:** medio mediante el que una persona interactúa con un sistema.
- **Usuario:** persona que utiliza la aplicación o el sitio web.
- **Contenido:** información que se presenta: textos, imágenes, datos o controles.
- **Acción:** tarea que la interfaz permite realizar, por ejemplo buscar, registrarse o comprar.
- **Diseño visual:** organización y apariencia de los elementos que aparecen en pantalla.

## 4. La comunicación visual en la web

La comunicación visual transmite información mediante elementos que se perciben con la vista. En una interfaz web intervienen, entre otros:

- La posición de los elementos.
- Su tamaño y forma.
- El espacio que los separa.
- El contraste entre elementos.
- Los colores.
- La tipografía.
- Los iconos, imágenes y otros recursos gráficos.

Estos elementos transmiten información incluso antes de leer el contenido. Por ejemplo, un botón destacado suele indicar una acción importante; una barra horizontal en la parte superior puede sugerir navegación; y un título de mayor tamaño suele señalar el comienzo de una sección.

El diseño debe estar al servicio del mensaje. Si una página tiene una apariencia atractiva, pero el usuario no encuentra el botón para completar una tarea, la comunicación no está funcionando correctamente.

### 4.1. Emisor, mensaje, canal y receptor

Podemos interpretar una interfaz mediante un esquema sencillo:

| Elemento | En una interfaz web                                        |
| -------- | ---------------------------------------------------------- |
| Emisor   | Organización, empresa o persona que publica el sitio       |
| Mensaje  | Información y acciones que ofrece                          |
| Canal    | Pantalla y navegador mediante los que se muestra           |
| Receptor | Persona que utiliza la web                                 |
| Código   | Convenciones visuales, textos, iconos y patrones conocidos |

El diseño puede fallar si el código visual no resulta comprensible para el receptor. Un icono ambiguo o una etiqueta poco clara pueden provocar errores.

### 4.2. Funciones de una interfaz

Una interfaz bien planificada debe:

1. **Informar:** presentar los datos necesarios.
2. **Orientar:** mostrar dónde se encuentra el usuario y qué opciones tiene.
3. **Facilitar acciones:** permitir completar tareas sin pasos innecesarios.
4. **Dar respuesta:** comunicar si una acción se ha realizado, si falta información o si se ha producido un error.
5. **Mantener coherencia:** utilizar patrones reconocibles en las distintas pantallas.

## 5. Principios básicos de diseño

### 5.1. Claridad

La información debe poder entenderse sin esfuerzo innecesario. Para mejorar la claridad:

- Utiliza textos concretos.
- Evita presentar demasiadas opciones simultáneamente.
- Agrupa la información relacionada.
- Diferencia los elementos interactivos del contenido informativo.
- No utilices adornos que dificulten la lectura.

**Ejemplo:** un formulario con etiquetas visibles como «Correo electrónico» y «Contraseña» es más claro que otro que solo contiene dos campos vacíos.

### 5.2. Jerarquía visual

La jerarquía visual indica qué elementos deben llamar la atención primero, después y al final. Se puede construir mediante tamaño, posición, contraste, espacio y peso visual.

Una pantalla puede tener esta jerarquía:

1. Título principal.
2. Mensaje o explicación.
3. Acción principal.
4. Información secundaria.

La jerarquía tipográfica y el uso detallado del color se estudiarán en sesiones posteriores.

### 5.3. Consistencia

Los elementos que cumplen la misma función deberían tener una apariencia y un comportamiento similares.

Por ejemplo, si todos los botones principales de una aplicación tienen la misma forma y estilo, el usuario aprende a reconocerlos. Cambiar de aspecto sin motivo aumenta la incertidumbre.

### 5.4. Proximidad

Los elementos relacionados deben aparecer próximos entre sí. Una etiqueta debe estar cerca del campo al que pertenece; el título debe estar cerca del contenido que introduce.

La proximidad ayuda a interpretar qué elementos forman un mismo grupo.

### 5.5. Alineación

Alinear los elementos siguiendo referencias comunes crea orden. Una pantalla donde títulos, textos y controles comienzan en posiciones distintas sin una razón clara puede parecer desorganizada.

### 5.6. Contraste

El contraste permite diferenciar elementos. Puede existir contraste de tamaño, forma, posición, tono o tipografía. Debe utilizarse para comunicar importancia y facilitar la percepción, no para convertir todos los elementos en protagonistas.

### 5.7. Equilibrio

El equilibrio visual consiste en distribuir el peso de los elementos de forma que la composición no parezca accidentalmente inclinada hacia una zona. No significa que ambos lados deban ser idénticos: una composición asimétrica también puede estar equilibrada.

## 6. Ejemplo comentado: pantalla de acceso

Imagina una pantalla de inicio de sesión con estos elementos:

- Logotipo de la aplicación.
- Título «Iniciar sesión».
- Campo de correo electrónico.
- Campo de contraseña.
- Botón «Entrar».
- Enlace «He olvidado mi contraseña».

Una organización clara podría colocar el logotipo arriba, el título antes del formulario, cada etiqueta junto a su campo, el botón después de los campos y el enlace de recuperación en una posición secundaria.

**¿Por qué funciona?**

- La proximidad relaciona cada etiqueta con su campo.
- La alineación facilita recorrer el formulario.
- La jerarquía hace que el título y el botón principal destaquen.
- La consistencia permite reconocer patrones conocidos.
- La claridad evita que el usuario tenga que adivinar qué debe introducir.

## 7. Análisis paso a paso de una interfaz

Para analizar una pantalla, sigue este procedimiento:

1. Identifica el objetivo principal de la página.
2. Enumera la información que presenta.
3. Localiza las acciones disponibles.
4. Observa qué elemento atrae primero la atención.
5. Comprueba si los elementos relacionados están agrupados.
6. Revisa si existe una alineación común.
7. Detecta elementos que compiten por llamar la atención.
8. Propón mejoras y justifica cada una mediante un principio de diseño.

No basta con decir «queda mejor». Una valoración de diseño debe explicar qué problema resuelve.

## 9. Reto: una interfaz que se entiende

Diseña en papel la distribución general de una pantalla para una biblioteca digital. Debe permitir buscar libros, consultar novedades y acceder a la cuenta personal.

No elijas todavía colores ni tipografías definitivas. Céntrate en qué información debe aparecer, qué acciones son importantes y cómo agrupar los elementos.

Entrega un boceto acompañado de cinco decisiones justificadas.

## 10. Errores frecuentes

- Confundir diseño visual con decoración.
- Dar la misma importancia a todos los elementos.
- Utilizar muchos estilos diferentes sin un criterio común.
- Agrupar elementos solo porque queda espacio.
- Justificar una decisión diciendo únicamente «me gusta más».
- Olvidar el objetivo real de la página.

## 11. Buenas prácticas

- Empieza por el objetivo y las tareas del usuario.
- Prioriza la información importante.
- Agrupa los elementos relacionados.
- Mantén patrones visuales consistentes.
- Utiliza el espacio para separar y organizar.
- Comprueba el diseño con tareas reales: ¿puede una persona encontrar lo que necesita?

## 12. Resumen

La interfaz es un medio de comunicación entre un sistema y sus usuarios. Su diseño debe facilitar la comprensión, la orientación y la realización de tareas. Claridad, jerarquía, consistencia, proximidad, alineación, contraste y equilibrio son principios que ayudan a organizar la información y reducir la confusión.
