# S05. Identidad visual y guías de estilo web

## 1. Introducción

Una web suele formar parte de una organización, un producto o un servicio. Su apariencia debe transmitir una identidad reconocible y mantenerse coherente en sus distintas páginas.

Una guía de estilo recoge las decisiones visuales que deben respetarse durante el diseño y desarrollo. Evita que cada pantalla parezca pertenecer a una aplicación distinta y facilita el trabajo en equipo.

## 2. Objetivos

- Comprender qué es la identidad visual.
- Identificar los elementos de una guía de estilo.
- Documentar colores, tipografías y componentes.
- Interpretar un manual de estilo existente.
- Aplicar criterios comunes a varias pantallas.

## 3. Conceptos previos

Se recomienda dominar los principios de consistencia, jerarquía, tipografía y color de las sesiones anteriores.

## 4. Identidad visual

La identidad visual es el conjunto de recursos gráficos que permiten reconocer una marca, organización o producto.

Puede incluir:

- Logotipo y sus variantes.
- Paleta de colores.
- Tipografías.
- Estilo de iconos e ilustraciones.
- Tratamiento de fotografías.
- Formas, bordes y recursos gráficos.
- Criterios de composición.

La identidad no debe confundirse con toda la experiencia de usuario. Es una parte de la comunicación visual, pero no sustituye la planificación de tareas, contenidos y navegación.

## 5. ¿Qué es una guía de estilo?

Es un documento que define cómo deben utilizarse los elementos visuales y qué reglas deben mantenerse.

Una guía útil debe ser:

- Clara: las reglas se entienden.
- Aplicable: permite tomar decisiones concretas.
- Consistente: no contiene instrucciones contradictorias.
- Reutilizable: sirve para distintas pantallas.
- Mantenible: puede actualizarse cuando cambia el producto.

## 6. Contenido de una guía de estilo

### 6.1. Identidad y marca

Incluye el nombre del producto, logotipo, variantes permitidas y recomendaciones de uso. Puede especificar tamaños mínimos, espacio de protección y fondos adecuados.

### 6.2. Paleta de color

Debe incluir valores exactos y funciones. No basta con indicar «azul corporativo»: es necesario documentar el código y dónde se utiliza.

Ejemplo:

| Nombre | Valor de ejemplo | Función |
|---|---|---|
| Principal | `#2457A6` | Acción prioritaria |
| Secundario | `#5B83C4` | Elementos de apoyo |
| Fondo | `#F5F7FA` | Fondo general |
| Texto | `#202633` | Texto principal |
| Éxito | `#237A4B` | Confirmaciones |

Los valores son ilustrativos; cada proyecto debe definir los suyos.

### 6.3. Tipografía

Documenta la familia principal, familias alternativas, niveles de títulos, párrafos y usos especiales. Indica qué hacer si la fuente preferida no está disponible.

### 6.4. Componentes visuales

Una guía puede documentar:

- Botones.
- Campos de formulario.
- Tarjetas.
- Menús.
- Avisos.
- Paneles.
- Enlaces.

Para cada componente conviene especificar su función, variantes y reglas de uso.

### 6.5. Espaciado y composición

Se pueden definir márgenes, separaciones, anchos máximos, alineaciones y reglas de composición. El objetivo es que las pantallas compartan un lenguaje visual.

## 7. Interpretar y aplicar una guía

Al recibir una guía de estilo:

1. Identifica los elementos obligatorios.
2. Localiza los valores exactos de color y tipografía.
3. Revisa las variantes de componentes.
4. Comprueba las reglas de composición.
5. Identifica usos permitidos y prohibidos.
6. Aplica las reglas a la pantalla que estás diseñando.
7. Anota cualquier decisión que la guía no resuelva.

No inventes una regla y la atribuyas al manual. Si falta información, registra la duda para que se decida.

## 8. Ejemplo: coherencia entre dos pantallas

Imagina una web con una página de acceso y otra de catálogo. Ambas deberían compartir:

- El mismo tratamiento del logotipo.
- La misma familia tipográfica.
- Los mismos colores de acción.
- El mismo aspecto para botones equivalentes.
- Criterios comunes de espaciado.

La distribución puede cambiar porque sus objetivos son diferentes, pero la identidad debe seguir siendo reconocible.

## 9. Actividades

### Nivel 1. Fundamentos

**E13. Partes de una guía de estilo**

Enumera los apartados que debería incluir una guía de estilo para una web y explica la finalidad de cada uno.

**Objetivo:** comprender la función de la documentación visual.

**Resultado esperado:** índice comentado de una guía.

### Nivel 2. Aplicación

**E14. Guía de estilo inicial**

A partir de la paleta y sistema tipográfico que has diseñado en sesiones anteriores, crea una guía de estilo inicial para una biblioteca digital.

Incluye identidad provisional, colores, tipografía, botones, tarjetas y campos de formulario.

**Objetivo:** documentar decisiones visuales reutilizables.

**Resultado esperado:** documento organizado con tablas y ejemplos.

### Nivel 3. Razonamiento

**E15. Detecta incoherencias**

Dos páginas de la misma aplicación usan logotipos distintos, botones con estilos diferentes, colores principales no coincidentes y títulos con escalas incompatibles.

Identifica las incoherencias y propone un procedimiento para corregirlas.

**Objetivo:** evaluar la consistencia de una interfaz.

**Resultado esperado:** lista priorizada de problemas y plan de corrección.

## 10. Reto: mini manual de identidad

Elabora una guía de estilo de dos o tres páginas para una aplicación educativa ficticia. Otra persona debería poder utilizarla para diseñar una pantalla sin preguntarte qué colores, tipografías o botones debe elegir.

## 11. Errores frecuentes

- Crear una guía que solo contiene colores.
- No especificar valores exactos.
- Documentar componentes sin explicar su función.
- Incluir reglas contradictorias.
- No contemplar variantes.
- Diseñar cada pantalla de forma independiente.

## 12. Buenas prácticas

- Documenta decisiones, no solo imágenes.
- Incluye ejemplos de uso correcto e incorrecto.
- Utiliza nombres consistentes para los elementos.
- Mantén la guía actualizada.
- Distingue reglas obligatorias de recomendaciones.
- Comprueba la guía en más de una pantalla.

## 13. Resumen

La identidad visual permite reconocer un producto. La guía de estilo documenta cómo aplicar sus recursos: marca, colores, tipografía, componentes y composición. Su finalidad es mantener coherencia y facilitar el trabajo de diseño y desarrollo.
