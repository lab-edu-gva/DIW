# DIW – Práctica: Diseño de una tarjeta profesional de cursos

**Duración:** 60 minutos  
**Nivel:** Intermedio  
**Tecnologías:** HTML5 y CSS3  
**Modalidad:** Individual

## 1. Objetivo de la práctica

En esta actividad vas a diseñar una tarjeta de presentación para un curso online, como las que podemos encontrar en plataformas profesionales de formación.

No queremos una tarjeta básica con una imagen y cuatro textos. El objetivo es conseguir un diseño cuidado, moderno y atractivo, prestando especial atención a la distribución de los elementos, los espacios, los colores, las sombras y las interacciones.

Esta tarjeta será la base de las siguientes prácticas, en las que construiremos un catálogo completo de cursos utilizando CSS Grid.

## 2. Preparación del proyecto

Crea una carpeta llamada `tarjeta-cursos`.

Dentro de ella organiza los archivos de la siguiente manera:

- Un archivo `index.html`.
    
- Un archivo `styles.css`.
    
- Una carpeta llamada `img` para guardar las imágenes.
    

Realiza la conexión entre el documento HTML y la hoja de estilos CSS.

Busca una imagen relacionada con programación, tecnología o desarrollo web. Guárdala dentro de la carpeta `img`.

**Importante:** toda la estructura HTML y todos los estilos CSS deben ser creados por ti. No se proporciona código resuelto.

## 3. Diseño que debes construir

Vas a crear una tarjeta con la información de un curso de formación.

La tarjeta debe contener los siguientes elementos, en este orden:

1. Una imagen representativa del curso.
    
2. Una pequeña etiqueta superpuesta sobre la imagen que indique «MÁS POPULAR».
    
3. La categoría del curso.
    
4. El título del curso.
    
5. Una descripción de aproximadamente tres líneas.
    
6. Una zona de información con la duración y el nivel.
    
7. Una línea divisoria horizontal.
    
8. Una zona inferior con el precio y un botón para consultar el curso.
    

Utiliza como contenido de referencia:

- Categoría: DESARROLLO WEB.
    
- Título: Desarrollo Web Full Stack.
    
- Descripción: Aprende a crear aplicaciones web modernas utilizando HTML, CSS, JavaScript y tecnologías del lado del servidor.
    
- Duración: 40 horas.
    
- Nivel: Intermedio.
    
- Precio: 89,90 €.
    
- Botón: Ver curso.
    

## 4. Desarrollo paso a paso

### Paso 1. Preparar la página (5 minutos)

Comienza trabajando sobre el documento completo.

Consigue que la página tenga las siguientes características:

- Elimina los márgenes predeterminados del navegador.
    
- Utiliza una tipografía moderna y fácil de leer.
    
- Establece un color de fondo gris muy suave.
    
- Haz que el contenido aparezca centrado horizontal y verticalmente.
    
- Utiliza Flexbox para conseguir el centrado.
    

**Pistas:**

- Investiga las propiedades `display`, `justify-content` y `align-items`.
    
- Recuerda que puedes utilizar `min-height` para conseguir que un elemento ocupe como mínimo toda la altura de la ventana.
    
- Investiga qué hace `box-sizing`.
    

### Paso 2. Crear el contenedor de la tarjeta (8 minutos)

Ahora trabaja sobre el elemento principal de la tarjeta.

Debe tener estas características:

- Fondo blanco.
    
- Anchura aproximada de 380 píxeles.
    
- Bordes redondeados.
    
- Una sombra suave alrededor.
    
- Sin ocupar toda la pantalla.
    
- El contenido no debe sobresalir de los bordes redondeados.
    

Busca una combinación de sombra que aporte profundidad sin resultar exagerada.

**Pistas:**

Investiga las propiedades:

- `width`
    
- `max-width`
    
- `background-color`
    
- `border-radius`
    
- `box-shadow`
    
- `overflow`
    

### Paso 3. Diseñar la imagen (8 minutos)

La imagen debe ocupar todo el ancho de la tarjeta.

Características:

- Altura aproximada de 210 píxeles.
    
- Debe ocupar todo el espacio disponible.
    
- No debe deformarse.
    
- No debe dejar espacios blancos alrededor.
    
- Debe integrarse correctamente con las esquinas superiores de la tarjeta.
    

**Reto:** coloca la etiqueta «MÁS POPULAR» encima de la imagen, en su esquina superior derecha.

La etiqueta debe tener:

- Fondo de color destacado.
    
- Texto blanco.
    
- Tamaño de letra pequeño.
    
- Bordes redondeados.
    
- Separación respecto a los bordes de la imagen.
    

**Pistas:**

Investiga `object-fit`, `position: relative` y `position: absolute`.

### Paso 4. Dar formato al contenido (10 minutos)

Debajo de la imagen debes colocar toda la información del curso.

Organiza los elementos verticalmente y utiliza espacios coherentes entre ellos.

Aplica los siguientes estilos:

**Categoría:**

- Texto en mayúsculas.
    
- Tamaño pequeño.
    
- Color azul o similar.
    
- Grosor de letra destacado.
    

**Título:**

- Tamaño aproximado de 23 píxeles.
    
- Texto oscuro.
    
- Grosor de letra importante.
    
- Separación adecuada respecto a la categoría.
    

**Descripción:**

- Color gris.
    
- Tamaño aproximado de 14 píxeles.
    
- Altura de línea cómoda para facilitar la lectura.
    
- No debe quedar demasiado pegada al título.
    

No olvides aplicar un espacio interior adecuado al contenido de la tarjeta.

**Pistas:** investiga `font-size`, `font-weight`, `line-height`, `color` y `margin`.

### Paso 5. Distribuir la información del curso (7 minutos)

Debajo de la descripción debes colocar dos elementos en una misma línea:

- Duración: 40 horas.
    
- Nivel: Intermedio.
    

Deben aparecer separados y correctamente alineados.

Puedes utilizar pequeños iconos o símbolos para acompañar cada información.

La distribución debe ser equilibrada y no debe provocar que los elementos se amontonen.

**Pistas:**

Investiga cómo utilizar Flexbox para colocar elementos en una misma fila y distribuir el espacio entre ellos.

### Paso 6. Crear la zona inferior (7 minutos)

Añade una línea divisoria horizontal para separar la información general de la zona de compra.

Debajo de ella debes colocar dos elementos:

**A la izquierda:**

- Una pequeña etiqueta que indique «Desde».
    
- El precio del curso, 89,90 €.
    
- El precio debe destacar visualmente.
    

**A la derecha:**

- Un botón con el texto «Ver curso».
    
- Fondo azul.
    
- Texto blanco.
    
- Bordes redondeados.
    
- Espaciado interior suficiente.
    

Ambos elementos deben quedar alineados verticalmente y distribuidos en una misma fila.

**Pistas:** utiliza Flexbox y estudia las propiedades `justify-content`, `align-items` y `gap`.

### Paso 7. Añadir interactividad visual (8 minutos)

Ha llegado el momento de darle un acabado profesional.

Cuando el usuario pase el ratón sobre la tarjeta:

- La tarjeta debe elevarse ligeramente.
    
- La sombra debe hacerse un poco más visible.
    
- El movimiento debe ser suave.
    

Cuando el usuario pase el ratón sobre el botón:

- Debe cambiar ligeramente de color.
    
- Puede aumentar ligeramente de tamaño.
    
- Debe mostrar una transición suave.
    

También puedes conseguir que la imagen aumente ligeramente de tamaño al pasar el ratón sobre ella.

**Pistas:**

Investiga:

- `:hover`
    
- `transition`
    
- `transform`
    
- `scale()`
    
- `translateY()`
    

## 5. Comprobaciones finales

- La tarjeta aparece centrada en la pantalla.
    
- La imagen tiene las dimensiones adecuadas.
    
- La etiqueta aparece encima de la imagen.
    
- Los textos tienen una jerarquía visual clara.
    
- La duración y el nivel aparecen en la misma línea.
    
- El precio y el botón están correctamente alineados.
    
- La tarjeta tiene una sombra elegante.
    
- Los efectos hover funcionan correctamente.
    
- El diseño se adapta a pantallas pequeñas.
    
- El código HTML está correctamente organizado y el CSS está separado.
    

## 6. Reto adicional

Si terminas antes de tiempo, intenta mejorar todavía más tu diseño.

1. Añade una etiqueta adicional que indique «CERTIFICADO».
    
2. Consigue que la imagen tenga un efecto de zoom al pasar el ratón.
    
3. Diseña una segunda versión de la tarjeta con colores oscuros.
    
4. Añade una pequeña valoración del curso mediante estrellas.
    
5. Mejora la adaptación de la tarjeta para dispositivos móviles.
    

**Resultado esperado:** una tarjeta de curso con apariencia profesional, que podría utilizarse perfectamente en una plataforma comercial de formación online.
